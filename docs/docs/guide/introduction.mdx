# Introduction

AstroBlocks is a Scratch 3.0 editor built on top of [TurboWarp](https://turbowarp.org/). It runs in your browser at [astroblocks.hermits.cc](https://astroblocks.hermits.cc/) and needs no account or install.

## What it adds

- **Extra blocks** in the control, data, events, looks, operators, sensing and sound categories.
- **Server mode**, which runs a project under Node as a web server. Projects answer requests with the blocks in the Web Server extension. See [Server mode](/server/).
- **Language additions** that a project opts into: type annotations like `score: number`, and sprites as classes with instances, fields and methods. See [Language](/language/).
- **Rubble**, the AstroBlocks mascot, as the default sprite.

Everything TurboWarp has is still there: the compiler, addons, custom extensions and packaging.

## Compatibility

Projects made in Scratch or TurboWarp open in AstroBlocks and behave the same way. A project that uses no AstroBlocks blocks still opens in TurboWarp, so you can move it back at any time.

A project that does use AstroBlocks blocks needs AstroBlocks to run those blocks.
