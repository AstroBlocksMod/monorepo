# Language

AstroBlocks adds to the Scratch language without changing what is already there. Every addition on these pages is something a project opts into, by adding an extension. A project that does not opt in runs exactly as it does in Scratch and TurboWarp.

## What there is

- [Types](./types): give a variable, a custom block input or a custom block a type, like `score: number`. Names without a type stay as flexible as they always were.
- [Classes](./classes): use a sprite as a class. Make instances that each have their own variables, and call their custom blocks from any sprite.
- [Protocols](./protocols): say what custom blocks and variables a sprite must have, and treat every sprite that has them the same way.
- [Functions](./functions): keep a piece of code in a variable, pass it around and call it later, and use it to change, filter and combine lists.
- [Reference values](./references): what an instance or a function is when it sits in a variable or a list, and how the blocks you already know treat it.

## Projects that use these

A project that uses one of these extensions needs AstroBlocks to open, the same as any project that uses AstroBlocks blocks. TurboWarp does not know the extensions and will refuse to load it.

The other direction always works. Projects from Scratch and TurboWarp open in AstroBlocks and behave the same.
