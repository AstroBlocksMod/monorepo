# Contributing

AstroBlocks lives in one repository, [AstroBlocksMod/monorepo](https://github.com/AstroBlocksMod/monorepo). It is a pnpm workspace that holds the editor and every library it is made of, each one a fork of its TurboWarp repository.

Setup, workspace commands and the pull request process are in [CONTRIBUTING.md](https://github.com/AstroBlocksMod/monorepo/blob/main/.github/CONTRIBUTING.md).

## Editing these docs

This site is built with [Rspress](https://rspress.rs/) from the `docs/` folder of the repository. Pages are Markdown or MDX files under `docs/docs/`, and the sidebar for each section comes from its `_meta.json`.

```sh
pnpm --filter astroblocks-docs run dev
```

That serves the site locally with live reload. Every page also has an edit link at the bottom that opens the file on GitHub.
